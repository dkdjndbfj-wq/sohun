# NTAG213 设备工作台使用说明

更新：2026-09-09。本次已实现客户端、Android NFC、配套 API 和官网落地页；客户端数据库为
schema **56**，服务端至少需要 migration **27**。本机自动化验收已完成；生产服务切换、真实
NFC/AMS、手机系统派发和打印机现场验证仍以部署记录及实测为准。

旧的 2026-09-08 本地验证包不能代表当前 schema 56 / migration 27 产物；发布时请使用本轮构建脚本生成并核对 SHA-256。Windows 包须完整解压后运行目录中的 `sohun.exe`，客户端更新不能替代配套服务端和官网更新。

## 两种标签各自做什么

| 标签 | 功能 |
| --- | --- |
| CUID/FUID | 耗材资料、写卡登记、扫码入库、实际净重、余量、消耗、换卷和标签周期 |
| NTAG213 | 定位打印机，进入设备状态、故障、摄像头入口和维护工作台 |

NTAG213 不写入耗材资料、不创建耗材库存，也不参与余量或消耗计算。标签里只有不含凭据的设备入口；读到标签不等于获得设备权限。

耗材资料、写卡、读取登记和批量加库存全部转到 [CUID/FUID 手机说明](手机RFID模板使用说明.md)。
同一张 CUID/FUID 资料卡可重复使用；NTAG213 的设备入口不会调用任何耗材接口。

## 首次使用

1. 更新桌面个人版和 Android 客户端。客户端数据库为 schema 56；设备接口与个人库存批次回执需要配套服务端 migration 27（至少包含 migration 26 的设备表）。
2. 桌面、手机登录同一个 sohun 个人账号。这里使用的是 sohun 账号。
3. 桌面连接打印机后，打开 **设置 → 设备与连接 → 共享设备状态到手机**，开启共享，可点击“立即同步设备”。开关默认关闭，切换账号不会继承另一个账号的开启状态。
4. 手机打开 **我的 → 设备工作台**，下拉刷新并选择打印机。工作台显示该设备的状态、当前任务、进度、剩余分钟和温度；没有新数据时显示最后上报时间。
5. 点击 **制作设备标签**，确认覆盖目标标签，再将未锁定的标准 NTAG213 靠近手机。等待完整写入及回读校验通过，再把标签贴在对应打印机上。

写卡前检查账号对设备的访问权限；写卡后只有完整校验成功才会保存设备标签制作日志。取消、切账号、标签移开或校验失败不算制作成功。

## 日常使用

- 手机碰设备标签，或在工作台点击“扫描 NTAG213 设备标签”，进入对应设备。未登录时先登录，成功后继续打开原设备。
- 同一设备可制作多张快捷标签；它们都打开同一设备，不表示多台打印机或多卷耗材。
- 标签 URL 是 `https://sohun.top/device/<设备标识>`，应用也识别 `sohun://device/<设备标识>`。原生支持冷启动和运行中的 NFC/链接分发；Android 系统设置、默认应用和实际标签仍需验收。若出现应用选择窗口，应选择 sohun。
- 网页只提供“打开 sohun”和 Android 下载入口，不公开设备信息。Android 下载需配置官网 `SOHUN_ANDROID_DOWNLOAD_URL`；未配置时明确显示尚未准备，不跳到 Windows 安装包。
- 当前账号不能访问的设备、已停止共享的设备和失效标签会被拒绝。临时断网时，已经验证过的本账号设备可以显示本机保存的记录，并明确标为离线；写新标签仍需联网确认权限。

## 故障、摄像头与维护

设备页按设备标识筛选已同步的故障，支持查看记录、标记已读和填写处理情况。维护记录不会自动清除打印机的实际告警。

“记录保养 / 巡检”支持巡检、清洁、润滑、皮带检查、喷嘴更换、热端更换和故障处理，可记录日期、备注及下次维护日期。到期项目显示在设备列表与详情中；同类新维护记录会取代旧提醒。当前是应用内到期提示，没有新增系统推送或后台巡检任务。

断网时，维护记录先保存在本机并显示“待同步”；联网刷新后用同一事件 ID 补传。另一台同账号手机可以看到相同的记录，重复同步不会新增副本。

摄像头采用用户配置的 HTTPS 页面或直播链接，点击后由手机打开。没有配置时不会假装已有视频；本次未实现把所有机型的私有视频流自动转发到手机。摄像头链接不写入 NTAG213。

## 标签丢失、停用和恢复

- **使旧设备标签失效**：更新设备入口标识，旧标签不能再打开设备；随后重新制作标签。
- **停止设备共享**：已有标签失效，桌面状态上传不会偷偷恢复该设备。
- 在设备列表开启“显示已停止共享的设备”，进入详情后可恢复；恢复后需要重新制作标签。维护历史保留。

设备更名不会改变原有标签指向。设备入口只用于查看与维护；碰标签不会自动开始打印、加热、暂停或停止机器。
