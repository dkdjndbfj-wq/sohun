# 拓竹故障提醒：数据、链路与验收

核对日期：2026-09-06。范围：个人版 Windows 桌面、Android 手机端及同一 sohun 账号的提醒服务。

## 官方数据

数据来自 Bambu Studio 使用的[官方中文查询服务](https://e.bambulab.com/query.php?lang=zh-cn&v=0)，当前版本 `202608251159`。打包数据包含 4,450 个不同代码（3,357 个 HMS、1,093 个打印错误），保留设备文案差异后为 4,712 个条目；其中 106 个条目的官方说明为空，这些内部状态不触发故障弹窗。

数据覆盖耗材用尽、AMS / 外挂进退料、卡料断料、工具头和切刀、喷嘴与热床温控、风扇、运动与归零、调平与检测、存储及设备状态等官方当前公开说明。展示原文与应用按钮分开，不按关键词编造拓竹处理步骤，不执行自动恢复、进退料或打印命令。未知代码保留原码并提供官方查询入口。

同一个代码不能只存一条固定说明。按照[官方 HMS 查询实现](https://github.com/bambulab/BambuStudio/blob/master/src/slic3r/GUI/HMS.cpp)，以设备序列号前三位选择文案。离线包包含官方当前打包的七种设备前缀及通用库；其他前缀在收到故障时向官方查询。只发送前三位，不发送完整序列号、LAN 密码或拓竹账号凭据。在线结果按设备缓存 24 小时，失败保留离线库并在后续重试。没有匹配时显示未知状态，不套用另一设备的专属说明。

`scripts/update_bambu_fault_catalog.py` 可重新获取数据。资产中的 `sources` 保存每份原始响应的 URL、版本、计数和 SHA-256。核对入口：[HMS 官方索引](https://wiki.bambulab.com/zh/hms/home)。新机型和新固件仍需以官方后续数据及实际设备上报为准。

## 原来缺失的部分及修正

- [官方设备协议](https://github.com/bambulab/BambuStudio/blob/master/src/slic3r/GUI/DeviceCore/DevHMS.cpp)以 `attr`、`code` 两个 32 位字段组成 HMS；原实现忽略数值 `attr`，会匹配不到完整代码。等级 1/2 为错误，3 为警告，4 为信息。打印错误 `print_error` 使用独立的 8 位代码，不能补成 16 位 HMS。
- 主选打印机和后台连接的所有机器共用 `PrinterFaultMonitor`。同机、同代码在活动期保留一个事件，独立打印机各自记录；重复推送不重复弹窗。解除后重现生成新的事件。
- 设备未上报某字段是未知；明确空 HMS 只解除 HMS，打印错误归零只解除打印错误。格式损坏、断线或只上报温度不能当作故障解除。合并状态保留“该字段曾明确上报”的信息。
- Windows 增加应用弹窗、系统通知和标题栏故障中心入口。采用现有主题、圆角与毛玻璃组件，可搜索机器、内容及代码，查看当前故障和历史、复制信息、打开官方帮助。多项提醒通过业务弹窗队列串行展示。
- “知道了”和“标为已读”只表示已经看过，不能改变设备故障或恢复打印。故障解除保留历史。设置中可以独立关闭故障弹窗；系统通知继续服从已有系统通知和打印任务开关。

## 手机提醒与运行条件

手机增加“打印提醒”页，使用相同故障记录、原文与官方链接。个人账号隔离、分页、幂等重试和已读同步都在服务端实现。桌面断网时将事件保存在本地账号专属待发送队列，重连后重试；上传只包含展示所需字段和打印机散列标识。

电脑端需要保持运行（可以留在托盘）、连接打印机，并与手机登录同一 sohun 账号。手机打开时每 15 秒检查；允许系统通知后，Android 后台使用系统任务定期检查。按照[Android 官方调度说明](https://developer.android.com/develop/background-work/background-tasks/persistent/getting-started/define-work)，后台最小周期为 15 分钟，省电、网络、强制停止等条件可能进一步延迟。这是定期检查，不是 Bambu Handy / 厂商推送级别的即时后台通知。界面明确说明该区别并显示最近同步时间和失败状态。

后台任务使用仅允许读取本账号打印故障的短期凭据，7 天过期，应用打开时续期；不持有主账号刷新凭据。凭据通过 Android Keystore 加密存储，退出账号时清理任务和通知并尝试撤销凭据。Android 13+ 使用系统通知权限；通知点击进入提醒页。关闭/重开、前后台检查共用通知去重状态，已解除和已读会取消相应通知。

## 发布与验证

服务端迁移新增 v25 的故障记录、游标和后台只读凭据表；本地数据库在故障服务初始化时创建待发送表。需要同时发布配套桌面、手机和服务端；仅修改代码不会让已经安装的旧版本收到新功能。当前任务不直接替其他发布任务部署服务或覆盖安装包。

执行 `powershell -File scripts/verify_bambu_faults.ps1` 可运行故障解析、状态生命周期、界面及服务端专项。完整 Flutter / Node 测试仍由现有检查流程覆盖。UI 可运行 `flutter test --no-pub --dart-define=FAULT_UI_CAPTURE=true test/printer_fault_ui_test.dart` 生成浅色、深色、弹窗和手机大字号截图（本机字体仅用于可选视觉验收）。

实机验收需在配套版本安装后检查：Windows 托盘通知、手机通知授权/锁屏/省电、断线重连，以及真实设备故障发生、消失和再次出现。当前软件模拟及编译验证不能代替所有机型和固件的硬件验收。

- 官方在线版本与打包版本一致，固定核对脚本通过；最终故障 Flutter 专项 67 项通过，包含手机退出账号时丢弃在途响应、分页解除和通知权限拒绝的用例。
- 服务端完整测试 63 项通过，其中新增故障服务测试 3 项；验证账号隔离、后台凭据权限、重复提交、已读保留、解除防回滚及超过 200 条后的分页。
- 手机既有页面回归 11 项通过，2 项可选截图测试未启用。故障中心另外完成浅色、深色、主动弹窗、手机大字号的渲染和人工看图检查，截图位于 `电脑软件/build/fault-ui/`。
- 完整 Flutter 测试 919 项通过、4 项跳过；历史版本迁移用例在并行运行时触发原有 2 分钟时限，单独重跑 1 分 53 秒通过。没有把这次超时记为全量一次通过。
- 最终 `dart analyze lib test`：0 个错误、0 个警告，保留项目现有格式提示。Android `:app:compileDebugKotlin` 通过，包含新增通知权限、通知频道、加密凭据和后台任务代码；保留工具链已有弃用提示。
- 未部署线上 v25，也未覆盖用户现有安装包；本轮未执行真实打印机故障或手机锁屏通知的实机触发。
