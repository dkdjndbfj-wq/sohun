# 1.0.1+2 首个正式公开版本验证记录

验证日期：2026-09-12。此记录描述实际执行的自动化检查，不代表真实手机、NFC 标签与 AMS 已全部兼容。

## 本次固定规则

- 每个实物卷的容量固定为 1000g；余料入库保留实际余量，不把余量当成容量。
- 余量严格大于 30g 且不超过 1000g 才能重新装入或继续使用。30g 及以下保留记录，明确确认用完才结算。
- 一张 CUID/FUID 资料卡可重复用于批量入库，每次确认数量，每卷保留独立库存 UID；取消不入库。
- 普通取下后必须确认实际装入的卷；明确维修暂取才恢复原卷。换卷保留旧余量、任务分段和历史。
- NTAG213 仅进入设备工作台，不进入耗材资料、入库或余量接口。
- 历史异常规格保留供核对，不静默截断余额；多卷聚合库存仍可大于 1000g。
- 旧版把实测余量写入单卷容量时，开库和同步只将合法的低容量独立卷名义化为 1000g；余量、UID、入库回执、周期、历史和事件不变，聚合库存及大于 1000g 的异常值不改写。

## 启动页变化

启动与主界面使用同一原生窗口尺寸，取消窗口展开、裁剪与字标飞入效果。品牌区域只进行一次 280ms 淡入，初始化完成即以 180ms 淡出进入主界面；不再人为增加 900ms 等待。进度对应初始化阶段，关闭动画或系统要求减少动画时直接交接。

## 分发边界

Windows 安装器和便携版采用 Release 编译，未进行 Authenticode 签名；Android APK 采用长期发行密钥签名的 Release 构建。按项目所有者决定作为首个正式公开版本发布，公开资源边界以根目录 `PUBLIC_RELEASE_MANIFEST.md` 和 `电脑软件/THIRD_PARTY_NOTICES.md` 为准。

自动化验证使用隔离数据库与本地 HTTP 服务，没有写入用户真实库存或真实 NFC 卡片。真实 NFC/AMS 兼容性、升级安装覆盖和实际 GPU 启动帧率仍需要实机验收；不以单测或成功编译宣称“完美实现”。
