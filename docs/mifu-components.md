# Mifu 组件与研发来源

此页是技术附录，不是集群主界面的品牌文案。Mifu的产品身份与实际运行组件分别记录，不能通过改名改变模型来源。

| 层次 | 本项目维护的内容 | 基础依赖或历史来源 |
| --- | --- | --- |
| Mifu Core原生数值模型 | 640 参数共享两两比较 MLP、整数差值特征、独立训练权重、CPU FP64 推理和离线入口 | Python、PyTorch；不加载 Laya 基础权重/SDK/分词器 |
| 集群工作台 | Flutter交互、候选流程、输入契约、采集及复核链 | Flutter/Dart及项目已有依赖 |
| 历史兼容研究路径 | 本地领域微调、评估和兼容服务集成 | Laya 0.4.31、multilingual/mmBERT基础权重及其依赖 |

原生数值头采用本项目独立随机初始化训练，不复制兼容基础模型的编码器权重。其训练标签来自明确的合成数值目标，历史实验中还计算了冻结兼容模型的输出作对照及组合分支实验。原生包不使用组合分支；保留实验来源不等于推理仍依赖该基础模型。

历史模型、失败成绩、源码指纹、训练锁和原始评估报告保留原名称与来源，不改写成原生模型研究，也不删除旧结果。旧HTTP兼容服务加载原权重时，元数据仍反映实际基础来源；没有加载时不宣称任何基础模型已经在线。
